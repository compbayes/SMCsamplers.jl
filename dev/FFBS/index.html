SMCsamplers.FFBS! — Function
FFBS!(Draws, U, Y, A, B, C, Σₑ, Σₙ, μ₀, Σ₀; filter_output = false, sample_t0 = true)

Forward filtering and backward sampling from the joint smoothing posterior p(x1,...xT | y1,...,yT) of the state space model:

yₜ = Cxₜ + εₜ, εₜ ~ N(0,Σₑ) Measurement equation

xₜ = Axₜ₋₁+ Buₜ + ηₜ, ηₜ ~ N(0,Σₙ) State equation

where

xₜ is the n-dim state

uₜ is the m-dim control

yₜ is the k-dim observed data.

Y is a vector of length T where Y[t] is the observation at time t (a scalar or a k-vector). U holds the controls: a T-vector if m = 1, otherwise a T×m matrix with uₜ in row t. μ₀ and Σ₀ are the mean and covariance of the initial state vector x₀. A and C can be deterministically time-varying by passing 3D arrays with the time index last. Σₑ and Σₙ can be time-varying by passing a vector of T PDMat covariance matrices.

The draws are written in place into Draws, which is a (T + sample_t0)×n matrix for a single draw, or a (T + sample_t0)×n×nSim array for nSim draws. If sample_t0 is true, the first row holds the draw of x₀.

Returns nothing, or the filtered means (T×n) and covariances (n×n×T) if filter_output is true.

Forward filtering and backward sampling from the joint smoothing posterior p(x1,...xT | y1,...,yT) of the state space model with nonlinear measurement equation:

yₜ = C(xₜ) + εₜ, εₜ ~ N(0,Σₑ) Measurement equation

xₜ = Axₜ₋₁+ Buₜ + ηₜ, ηₜ ~ N(0,Σₙ) State equation

where

C(xₜ) is a non-linear function, evaluated as C(x, Cargs), with Jacobian ∂C(x, Cargs)

xₜ is the n-dim state

uₜ is the m-dim control

yₜ is the k-dim observed data.

The filter is the extended Kalman filter if maxIter == 1, otherwise the iterated extended Kalman filter with at most maxIter iterations and convergence tolerance tol on the change in the state mean. If linesearch is true, each iteration uses a backtracking line search.

Cargs is either fixed over time or a vector of length T with Cargs[t] used at time t.

Y is a vector of length T where Y[t] is the observation at time t (a scalar or a k-vector). U holds the controls: a T-vector if m = 1, otherwise a T×m matrix with uₜ in row t. μ₀ and Σ₀ are the mean and covariance of the initial state vector x₀. A can be deterministically time-varying by passing an n×n×T array. Σₑ and Σₙ can be time-varying by passing a vector of T PDMat covariance matrices.

The draws are written in place into Draws, which is a (T + sample_t0)×n matrix for a single draw, or a (T + sample_t0)×n×nSim array for nSim draws. If sample_t0 is true, the first row holds the draw of x₀.

Returns nothing, or the filtered means (T×n) and covariances (n×n×T) if filter_output is true.

SMCsamplers.FFBS_SLR! — Function
FFBS_SLR!(Draws, U, Y, A, B, condMean, condCov, param, Σₙ, μ₀, Σ₀, maxIter;
    α = 1, β = 0, κ = 0, filter_output = false, sample_t0 = true, nFailure = Ref(0))
FFBS_SLR!(Draws, U, Y, A, B, condMean, condCov, param, Σₙ, μ₀, Σ₀, maxIter,
    ScaleMat, Svec; kwargs...)

Forward filtering with the iterated posterior linearization filter (IPLF), which linearizes the measurement model by statistical linear regression (SLR) using the unscented transform, followed by backward sampling from the joint smoothing posterior p(x1,...xT | y1,...,yT) of the state space model:

yₜ ~ p(yₜ | xₜ) Measurement model

xₜ = Axₜ₋₁+ Buₜ + ηₜ, ηₜ ~ N(0,Σₙ) State equation

The measurement model enters only through its conditional moments condMean(param, x, t) = E(yₜ | xₜ = x) and condCov(param, x, t) = Cov(yₜ | xₜ = x). The IPLF runs at most maxIter iterations per time step. α, β and κ are the parameters of the unscented transform.

Y is a vector of length T where Y[t] is the observation at time t (a scalar or a k-vector). U holds the controls: a T-vector if m = 1, otherwise a T×m matrix with uₜ in row t. μ₀ and Σ₀ are the mean and covariance of the initial state vector x₀. A can be deterministically time-varying by passing an n×n×T array. Σₙ can be time-varying by passing a vector of T PDMat covariance matrices.

The draws are written in place into Draws, which is a (T + sample_t0)×n matrix for a single draw, or a (T + sample_t0)×n×nSim array for nSim draws. If sample_t0 is true, the first row holds the draw of x₀.

Returns nothing, or the filtered means (T×n) and covariances (n×n×T) if filter_output is true.

If the filter fails at some time step, nFailure[] is incremented and the function returns nothing early, leaving Draws unchanged.

A second method takes the extra positional arguments ScaleMat and Svec. At each t the n×n scaling matrix S = ScaleMat(param, μ, t) is evaluated at the current filtered mean μ, stored in Svec[:, :, t], and the state noise covariance is replaced by S * Σₙ * S.

SMCsamplers.FFBS_laplace! — Function
FFBS_laplace!(Draws, U, Y, A, B, Σₙ, μ₀, Σ₀, observation, θ;
    filter_output = false, sample_t0 = true, μ_init = nothing, max_iter = 100,
    fisherinfo = nothing, nFailure = Ref(0))
FFBS_laplace!(Draws, U, Y, A, B, Σₙ, μ₀, Σ₀, observation, θ, ScaleMat, Svec; kwargs...)

Forward filtering with a Laplace approximation in each measurement update, followed by backward sampling from the joint smoothing posterior p(x1,...xT | y1,...,yT) of the state space model:

yₜ ~ p(yₜ | xₜ) Measurement model

xₜ = Axₜ₋₁+ Buₜ + ηₜ, ηₜ ~ N(0,Σₙ) State equation

observation(θ, x, t) returns the distribution of yₜ given xₜ = x. The filtering posterior at each t is approximated by a normal distribution centered at its mode, found by Newton trust-region optimization with at most max_iter iterations starting from μ_init (defaults to the predicted mean), with covariance from the negative inverse Hessian at the mode.

If fisherinfo(θ, x, t) is given, it should return the n×n Fisher information of yₜ with respect to xₜ = x. The expected information (Fisher information plus the inverse of the predicted covariance) is then used in place of the observed information, both in the Newton trust-region iterations and for the covariance at the mode.

Y is a vector of length T where Y[t] is the observation at time t (a scalar or a k-vector). U holds the controls: a T-vector if m = 1, otherwise a T×m matrix with uₜ in row t. μ₀ and Σ₀ are the mean and covariance of the initial state vector x₀. A can be deterministically time-varying by passing an n×n×T array. Σₙ can be time-varying by passing a vector of T PDMat covariance matrices.

The draws are written in place into Draws, which is a (T + sample_t0)×n matrix for a single draw, or a (T + sample_t0)×n×nSim array for nSim draws. If sample_t0 is true, the first row holds the draw of x₀.

Returns nothing, or the filtered means (T×n) and covariances (n×n×T) if filter_output is true.

If the filter fails at some time step, nFailure[] is incremented and the function returns nothing early, leaving Draws unchanged.

A second method takes the extra positional arguments ScaleMat and Svec. At each t the n×n scaling matrix S = ScaleMat(θ, μ, t) is evaluated at the current filtered mean μ, stored in Svec[:, :, t], and the state noise covariance is replaced by S * Σₙ * S.

FFBS_montecarlo!(Draws, U, Y, A, B, Σₙ, μ₀, Σ₀, observation, θ;
    filter_output = false, sample_t0 = true, nMC = 1000, nFailure = Ref(0))

Forward filtering with a Monte Carlo Gaussian filter, followed by backward sampling from the joint smoothing posterior p(x1,...xT | y1,...,yT) of the state space model:

yₜ ~ p(yₜ | xₜ) Measurement model

xₜ = Axₜ₋₁+ Buₜ + ηₜ, ηₜ ~ N(0,Σₙ) State equation

observation(θ, x, t) returns the distribution of yₜ given xₜ = x. In each measurement update, nMC states are drawn from the predictive distribution and an observation is simulated for each; the Kalman gain is formed from the Monte Carlo estimates of the covariance of yₜ and the cross-covariance between xₜ and yₜ.

Y is a vector of length T where Y[t] is the observation at time t (a scalar or a k-vector). U holds the controls: a T-vector if m = 1, otherwise a T×m matrix with uₜ in row t. μ₀ and Σ₀ are the mean and covariance of the initial state vector x₀.
